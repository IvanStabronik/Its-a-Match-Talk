# Product Direction — Its a Match Talk

**Status:** Accepted 2026-07-25  
**Positioning:** Relationship clarity analyzer (not a rizz toy)

## One-liner

Paste or upload a chat → see **observable dynamics** (effort, interest trend, ghost risk) → get a concrete next step and 3 reply options.

## Why this wins for us

- Fits existing Its a Match brand, bot, and audience
- Pain is recurring → retention + subscription
- Stronger than one-shot color analysis; weaker ideas (aura, face rating, cheating tests) are out

## Priority stack

| Priority | Product | Role |

| **1** | Talk — chat dynamics analyzer | Core app |
| **2** | Red/green flag tracker | Module inside Talk |
| **3** | Attachment style | Optional module inside Talk |
| Side | Color analysis | Separate spare project |
| Kill | Rizz-check, aura score, face rating, loyalty tests | Do not build |

## Product principles (non-negotiable)

1. **Observable actions only** — who initiates, message length, gaps, cancellations. Not mind-reading.
2. **No clinical diagnoses** — never “narcissist”, “abuser”, “avoidant 94%”.
3. **Pseudo-certainty is a bug** — soft language: “по переписке видно…”, “возможный риск…”.
4. **Privacy-first** — screenshots on-device; conversation not stored after analysis; delete-all exists.
5. **Replies are the tail** — 3 variants support the insight, they are not the whole product.
6. **Re-analysis** — user can come back days later and see “лучше / хуже”.
