## Region profiles (v1)

### RU-Moscow
- **Характер:** прямой, уверенный, короткие фразы, без воды
- **Юмор:** лёгкая ирония, мемы умеренно
- **Избегать:** канцелярит, «уважаемая», чрезмерный пафос
- **Запрещённые фразы:** «моя королева», «ты одна такая», «даме», «сударь»
- **Max emoji:** 2

### RU-Piter
- **Характер:** ирония, самоирония, чуть отстранённый
- **Юмор:** сухой, «питерский» стёб
- **Избегать:** московский напор, пафос
- **Запрещённые:** «в столице так не делают», занудство

### RU-Regions
- **Характер:** теплее, проще, меньше сленга столиц
- **Избегать:** московский снобизм, сложные конструкции

### UA (v1.1 — если включишь)
- Ответы могут содержать укр. вкрапления только если user выбрал явно
- Не смешивать RU/UA в одном ответе без запроса

### KZ
- Уважительный тон, меньше фамильярности на старте
- Избегать российского политического контекста в примерах

### Diaspora-EU
- Русский без сленга RU TikTok
- Чуть более формальный register

## RU Anti-Cringe: banned phrases (starter list)

Добавить в `regionProfiles` и deterministic validator:

```
моя королева
ты одна такая
альфа-самец
сигма
нейротип
frame control
встречу у метро в 21:00 без контекста
привет, как дела (единственное сообщение без контекста)
ты мне так нужна
почему молчишь
ну ты и даёшь (унизительно)
```

## RU Dating app context (OCR hints)

Скриншоты часто из:
- **Tinder** — зелёные/белые bubbles
- **Bumble** — жёлтые accents
- **Pure** — тёмная тема
- **Mamba / Дайвинчик** — кириллица, специфичная вёрстка
- **Telegram** — если user скринит переписку
- **VK** — реже, но возможно

**Тест-набор OCR:** собери 10+ скриншотов каждого мессенджера до release.

## Typographic rules

- «ё» — допускается, не форсировать
- Тире — длинное (—), не дефис
- Нет «)))» больше 1 подряд в ответе (validator)
